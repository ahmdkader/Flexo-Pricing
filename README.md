# Flexo Costing Studio — تطبيق حساب تكلفة الفليكسو

## الرفع على GitHub Pages
1. فك ضغط الملف على جهازك.
2. أنشئ مستودعاً في GitHub أو افتح المستودع المطلوب.
3. من Add file → Upload files ارفع محتويات المجلد، وليس ZIP ولا المجلد الخارجي. يجب أن يكون index.html في الجذر مباشرة.
4. احفظ الملفات باستخدام Commit changes.
5. افتح Settings → Pages.
6. اختر Deploy from a branch ثم main ثم /(root) واضغط Save.
7. انتظر اكتمال النشر وافتح الرابط الذي يظهر في صفحة Pages.

دليل GitHub الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## التثبيت والاستخدام
- أندرويد: افتح رابط التطبيق في Chrome، ثم قائمة المتصفح واختر تثبيت التطبيق أو الإضافة للشاشة الرئيسية بحسب المتاح.
- آيفون: افتح الرابط في Safari واستخدم مشاركة ثم إضافة إلى الشاشة الرئيسية.
- الكمبيوتر: استخدم الرابط مباشرة أو خيار التثبيت إذا عرضه المتصفح.
- الحفظ محلي في المتصفح. لنقل التعديلات استخدم تصدير البيانات ثم استيرادها على الجهاز الآخر.
- افتح التطبيق عبر رابط الموقع؛ فتح index.html مباشرة من الملفات لا يكفي لتحميل بيانات التطبيق.
- يدعم العمل دون اتصال بعد أول تحميل ناجح وحفظ ملفات التطبيق في المتصفح؛ قد تؤثر إعدادات المتصفح أو مسح بياناته على ذلك.

## المحتويات
واجهة عربية/إنجليزية، وضع ليلي ونهاري، مقارنة السلندرات، تكلفة الماكينات، تسعير عادي وطبقتين، قاعدة السكاكين، طباعة PDF، وملف الإكسل الأصلي.

الحسابات الافتراضية: سلندر 117، تكلفة 154545.3785107376 جنيه، سعر بيع 309090.7570214752 جنيه. تم الحفاظ على قيم المصدر اليدوية؛ ملاحظاتها موضحة بالتطبيق.

الملفات تحتوي على بيانات وأسعار الملف الأصلي. عند نشر الموقع علناً تصبح هذه البيانات متاحة لزوار الموقع.

لا يحتاج التطبيق إلى npm أو عملية build أو مفاتيح سرية.
